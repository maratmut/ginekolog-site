# Лендинг Наиды Рамазановой

Одностраничный адаптивный сайт врача-гинеколога-хирурга на React, Vite и Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

Готовые статические файлы появятся в `dist/`.

## Перед публикацией

1. Заменить значения `CONTACTS` в `src/App.jsx` на реальные ссылки WhatsApp, Telegram и Instagram.
2. Подключить форму к CRM, почте или серверному обработчику — сейчас она работает в демонстрационном режиме.
3. Добавить подтверждённые фотографии врача, результаты и отзывы только после получения согласия на публикацию.
4. После выбора домена добавить абсолютный canonical URL, адрес и контакты в JSON-LD разметку `index.html`.
